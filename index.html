Format Soal Fill in the Blanks

Potongan kode Java valid disajikan dengan bagian kosong yang harus Anda isi tepat di posisinya:

Contoh soal
public class SegiEmpat {
    private double panjang;

    public SegiEmpat(double panjang) {
        this.panjang = panjang;
    }
}
  • Java bersifat case-sensitive — huruf besar/kecil berpengaruh.
  • Sistem mengabaikan spasi di tepi dan menormalkan whitespace ekuivalen.
  • Poin diberikan secara parsial untuk soal dengan banyak blank.

Panduan Kilat & Ringkasan Aturan Java PBO

1. Kata Kunci Utama

extends (pewarisan class), implements (interface), super(...) (panggil konstruktor induk, wajib baris pertama), this (referensi objek saat ini), static (milik class bersama), abstract (tanpa implementasi), final (konstanta / tidak bisa di-override).

2. Urutan Hak Akses

Tersempit ke terluas: private → (default) → protected → public.

3. Overloading vs Overriding

Overloading (compile-time): nama sama, parameter berbeda, satu class. Overriding (runtime): nama & parameter sama persis pada subclass, gunakan anotasi @Override.

4. Array vs ArrayList

Array: ukuran tetap, properti .length, indeks arr[0]. ArrayList: dinamis, method .size(), .add(x), .get(i).

5. Tips Menjawab Fill in the Blanks

Perhatikan tanda kurung dan titik koma di sekitar blank. Java bersifat case-sensitive. Tekan Tab atau Enter untuk berpindah kotak kosong.
